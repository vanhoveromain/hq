# Geist typeface usage

Approved primary: Geist Sans. Approved optional companion: Geist Mono for technical and fixed-width content.

Get authentic font files from official distribution. Do not use the typeface approximation used in PDF exports as a substitute.
Official references: https://vercel.com/font and https://github.com/vercel/geist-font

Suggested CSS:
```css
body { font-family: "Geist Sans", system-ui, -apple-system, sans-serif; }
pre, code, .technical-id { font-family: "Geist Mono", ui-monospace, monospace; }
.metric { font-variant-numeric: tabular-nums; }
```
No font files are redistributed in this package.
