# HQ — Complete Designer Handoff v1.0

**Start here:**
1. Read `01_Brand_Book/HQ_Brand_Guidelines.pdf` or `HQ_Brand_Guidelines_FULL.md`.
2. Read `07_Handoff_Checklists/PRODUCTION_STATUS.md` to distinguish approved creative choices from provisional engineering specifications.
3. Open `06_References/HQ_Approved_User_Reference_95x97.png`: this is the newest approved HQ logo, superseding the old 01 Balanced monogram.
4. Use `02_Logos/Products/` for four approved product symbol concepts.
5. Review `03_Colour_and_Tokens/` and `05_UI_Examples/HQ_UI_Preview.html` when implementing UI.

**IMPORTANT:** The parent master SVG in this package is an *automatically traced provisional rendition* of a small uploaded PNG. It is NOT a designer-approved original vector master. Redraw and sign off before production. The package is a complete creative/design brief and working asset collection, not proof of legal originality or accessibility certification.

**Included:** Long-form Markdown brand manual, designed PDF brand book, parent logo reference and trace, 4 product symbol SVGs and PNGs, colour tokens CSS/JSON/CSV, contrast table, typography notes, static HTML example, designer QA checklist. No fonts are redistributed.
